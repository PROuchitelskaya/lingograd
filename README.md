# ЛИНГОГРАД: ЯЗЫК НА ГРАНИ

Командная браузерная игра по русскому языку для 5–11 классов. Спецвыпуск ко Дню знаний:
класс собирается в команды и восстанавливает город Лингоград, у которого злодей Хаос
похитил буквы, окончания и запятые.

- **Учитель** открывает `/teacher`, выбирает класс и создаёт игру — на экране появляется
  QR-код и четырёхсимвольный код.
- **Ученики** заходят с телефонов на тот же адрес, вводят код, выбирают команду.
- Игра идёт синхронно: у всех один таймер, одно задание, общая карта из пяти районов
  и финальная битва с Хаосом.

Один урок — 45 минут, 30 заданий, 15–40 участников.

---

## Быстрый запуск

```bash
python -m venv .venv && .venv/Scripts/python.exe -m pip install -r requirements.txt
```

```bash
.venv/Scripts/python.exe backend/main.py
```

Сервер поднимется на порту **4190** и напечатает адреса:

```
Ученики : http://192.168.x.x:4190/
Учитель : http://192.168.x.x:4190/teacher
```

Телефоны должны быть в той же сети (школьный Wi-Fi). Ничего собирать не нужно:
Node.js, npm и сборщики не используются, фронтенд — нативные ES-модули.

## Как проходит урок

| Шаг | Экран учителя | Экран ученика |
|---|---|---|
| 1 | Класс, число команд, длительность, режим | Лендинг |
| 2 | QR-код + код игры, список подключившихся | Ввод кода и имени, выбор команды |
| 3 | «НАЧАТЬ ИГРУ» | «С 1 сентября!», появление Хаоса |
| 4 | Текущее задание, правильный ответ, сколько ответили | Карта → миссия → задание |
| 5 | Пауза / пропустить / +5 минут / +15 секунд | Разбор ответа после каждого задания |
| — | На паузе время останавливается | На экране плашка «Учитель остановил игру» |
| 6 | Итоги, награды, разбор по районам, выгрузка CSV | Победа, рейтинг, награды |

Пять районов: Район слов (лексика), Лаборатория морфологии, Синтаксический мост,
Архив текстов, Башня Хаоса (финальная битва со шкалой энергии).

## Банк заданий

`backend/content/grade_5.json` … `grade_11.json` — по 30 заданий на класс
(6 на каждый район), 210 заданий всего. Поддерживаются все девять типов:

`single_choice`, `multiple_choice`, `true_false`, `sort`, `match`,
`text_input`, `punctuation`, `word_build`, `highlight`.

Формат задания:

```json
{
  "id": "g7_m01",
  "district": "morphology",
  "topic": "причастие",
  "difficulty": 2,
  "type": "single_choice",
  "points": 10,
  "time_limit": 30,
  "question": "Определите часть речи выделенного слова: РАСТУЩИЕ",
  "text": "Быстро растущие деревья закрыли окно.",
  "answers": ["Прилагательное", "Причастие", "Глагол", "Наречие"],
  "correct_answer": 1,
  "explanation": "Растущие — действительное причастие настоящего времени."
}
```

Поле `correct_answer` зависит от типа: индекс, список индексов, `true/false`,
строка (или список допустимых написаний), список позиций запятых. Для `sort`
и `match` правильный порядок задают сами поля `items` / `pairs` — игроку они
показываются перемешанными.

У каждого задания есть `hint` — короткая подсказка, которую ученик видит
после первой неверной попытки. Она наводит на правило, но не выдаёт ответ.

Чтобы добавить задание, допишите объект в нужный файл и перезапустите сервер.
Проверка ответов и подсчёт баллов происходят на сервере: правильный ответ не
уходит в браузер до конца раунда, варианты перемешиваются, повторная отправка
запрещена.

## Подсчёт баллов

- Верный ответ с первой попытки: `points` + до 50% бонуса за скорость.
- Верный со второй попытки: половина `points` (ошибка — часть игры, а не наказание).
- Две неудачные попытки или ответ, оставшийся неотправленным, — ошибка в статистике команды.
- Кто не нажал ничего, в точность команды не попадает.
- Пауза замораживает и таймер задания, и бонус за скорость: объяснение у доски
  не отнимает у класса баллы. «+15 секунд» расширяет окно задания, а не ломает счёт.

Награды в финале: 🧠 Мастера слова, ✍️ Повелители запятых, ⚡ Скоростная команда,
🎯 Снайперы правил, 🤝 Команда года. При равных показателях награда уходит команде,
у которой её ещё нет.

## Устройство проекта

```
backend/
  main.py        FastAPI: статика, REST, WebSocket-хаб
  game.py        игровая сессия: фазы, команды, очки, награды, аналитика
  content.py     загрузка банка, перемешивание, проверка ответов
  content/       banks: grade_5.json … grade_11.json
frontend/
  index.html
  js/
    main.js      точка входа (ученик или /teacher)
    net.js       WebSocket + автопереподключение
    student.js   экраны ученика
    teacher.js   панель учителя и разбор
    question.js  рендер девяти типов заданий
    qr.js        генератор QR-кода (свой, без CDN)
    audio.js     синтез звуков и музыки через WebAudio
    fx.js        листья, конфетти, кристаллы, буквы Хаоса
    art.js       SVG-иллюстрации
  styles/        tokens.css, base.css, screens.css
```

Сессии живут в памяти процесса: перезапуск сервера завершает начатую игру.
Комнаты старше шести часов удаляются автоматически.

## Что учтено из требований

- Праздничное оформление 1 сентября, палитра и градиенты из ТЗ, шрифт Manrope
  (при отсутствии интернета подставляется системный).
- Мобильная вёрстка от 360 px: зоны нажатия не меньше 48 px, ответы — от 56 px,
  ни один экран не скроллится по горизонтали, hover-механики нет.
- Звук и музыка синтезируются в браузере — файлов нет, работает офлайн;
  переключатели «Звук» и «Музыка» сохраняются на устройстве.
- Реконнект: при обрыве связи ученик возвращается в свою команду с её счётом,
  а если ответ не ушёл из-за сети, карточка разблокируется и просит нажать снова.
- Опоздавший к старту сразу попадает в самую маленькую команду и играет со всеми.
- Правильный ответ не появляется на проекторе во время задания: учитель открывает
  его кнопкой «Показать ответ» или видит в разборе.
- Доступность: правильно/неверно обозначены значком и словом, не только цветом;
  контраст текста проверен по WCAG AA; учитывается `prefers-reduced-motion`.

## Чего пока нет

- Админки для редактирования заданий через интерфейс — банк правится в JSON.
- Хранения результатов между запусками (нет базы данных): итоги урока выгружаются
  кнопкой «Скачать CSV» на экране результатов.
- Изображений в заданиях (поле в формате предусмотрено, рендер не сделан).
